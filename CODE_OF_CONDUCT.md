# Code of Conduct

## Our pledge

We want this project to be a friendly, harassment-free place for everyone, whatever their age, body, disability, ethnicity, gender identity and expression, level of experience, education, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be kind and patient, especially with newcomers.
- Give and take feedback gracefully. Critique code, not people.
- Assume good intent.

## Not acceptable

- Harassment, insults, or personal attacks.
- Sexual language or imagery.
- Publishing other people's private information.
- Using the game's techniques against systems you do not own or have no permission to test.

## Enforcement

Report problems to saurabhpathak394@gmail.com. Reports are handled privately. The maintainer may remove comments, code or contributors that break this code of conduct.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
